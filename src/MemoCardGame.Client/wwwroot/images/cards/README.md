# Card images

Add one image **per pair** (each pair uses the same image on both cards).

- **Naming:** `0.png`, `1.png`, `2.png`, … (or `0.jpg`, `1.jpg`, …)
- **Count:** For a 4×4 board you need **8** images (pairs 0–7). For 6×6 you need **18** (0–17).
- **Format:** PNG or JPG. Recommended size: at least 200×200 px (they are shown square, cropped to fit).

If a file is missing, the game falls back to placeholder images from the web.
